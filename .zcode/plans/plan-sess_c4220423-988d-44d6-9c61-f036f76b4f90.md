Migrate ClubHub from Bootstrap 4 (SB Admin 2 v4.1.3) to Bootstrap 5.3.x, in one contained commit on a clean tree.

**Preconditions**
- User commits or stashes current uncommitted changes (clubs/urls.py, config/urls.py) first.

**Steps**

1. **Assets**: Add Bootstrap 5.3.x dist (CSS + bundle.js with Popper 2) to `static/vendor/bootstrap/`. Remove jQuery, jquery-easing, and the dead DataTables/Chart.js/demo vendor dirs (unreferenced).

2. **CSS splice**: In `static/css/clubhub.css`, replace the compiled BS4 core (lines ~13–9,888) with the BS5 dist CSS. Keep the SB Admin 2 component layer and ClubHub custom layer (`.ch-*`, sortable headers, pagination) appended after it; audit that layer for BS4 internals (`.custom-*`, `.media`, `.form-group`, `.form.user` bits) and fix the few hits.

3. **JS**: Rewrite `static/js/sb-admin-2.js` as ~30 lines of vanilla JS (sidebar toggle classes, resize handler, scroll-to-top with CSS transitions / smooth scrolling — no jQuery APIs). Remove jquery + easing `<script>` tags from `base.html` and `auth_base.html`; load `bootstrap.bundle.min.js` (BS5).

4. **Templates sweep** (~25 files, mostly regexable renames):
   - `data-toggle/dismiss/target` → `data-bs-*` (dropdowns in base.html + person_register, logout modal, alerts)
   - `font-weight-bold` → `fw-bold` (×41); `mr-/ml-` → `me-/ms-` (×24); `mr-auto/ml-auto` → `mr-auto`→`me-auto`/`ms-auto`
   - `badge badge-*` → `badge bg-*` (×12, keep `text-dark` on warning)
   - `dropdown-menu-right` → `dropdown-menu-end`; `.close` → `btn-close` (add `btn-close-white` on dark navbar); `btn-block` → `d-grid` wrapper; `no-gutters` → `g-0`; `thead-light` → `table-light`; unwrap `input-group-append`
   - `clubs/settings.html`: `$("#removeImageModal").modal(...)` → `bootstrap.Modal.getOrCreateInstance(...)`; rewrite small jQuery in `person_register.html` as vanilla JS

5. **Form renderer**: `templates/django/forms/p.html`: `form-group` → `mb-3`; verify `.ch-float` labels and `.form-check` branch still style correctly under BS5.

6. **Theme CSS**: In `base.html` style block: `.badge-primary` → `.badge.bg-primary`; `.custom-select:focus` → `.form-select:focus`; adjust `.btn-primary:focus` box-shadow alpha to BS5 conventions if needed. `build_theme()` unchanged.

7. **Bump** `clubhub.css?v=` cache-buster.

8. **QA**: run `manage.py test` (should be unaffected); then manual click-through of all pages (dashboard, groups, schedule week + templates, attendance HTMX grid, personregister + import preview, invoices, notifications, club settings incl. logo/background modals and color previewer, login + password reset flows) checking dropdowns, modals, alerts, sidebar toggle, floating labels, pagination, and badges. Fix visual drift in the SB Admin 2 layer as found.

9. Update AGENTS.md tech-stack notes (BS5 conventions replace the "don't use BS5 classes" rule).
